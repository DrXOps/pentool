## Proxy मॉड्यूल

Proxy आपके ब्राउज़र और लक्ष्य के बीच HTTP/HTTPS ट्रैफ़िक को इंटरसेप्ट करता है।

### Proxy प्रारंभ करना

1. Proxy (`Shift+P`) पर जाएं
2. **Start Proxy** बटन क्लिक करें
3. डिफ़ॉल्ट `127.0.0.1:8888` पर सुनता है

### ब्राउज़र कॉन्फ़िगर करना

**Firefox:**
- Settings → Network → Manual proxy configuration
- HTTP Proxy: `127.0.0.1` Port: `8888`
- "Also use this proxy for HTTPS" सक्षम करें

**Chrome/Chromium:**
- एक्सटेंशन (FoxyProxy) या सिस्टम सेटिंग्स का उपयोग करें

### HTTP History

**HTTP History** टैब सभी इंटरसेप्ट किए गए अनुरोध दिखाता है:

- **ID** — अद्वितीय अनुरोध संख्या
- **Host** — लक्ष्य होस्ट
- **Method** — HTTP विधि (GET, POST, आदि)
- **URL** — अनुरोध पथ
- **Status** — प्रतिक्रिया कोड
- **Size** — प्रतिक्रिया आकार
- **Time** — निष्पादन समय

**क्रियाएं:**
- अनुरोध पर क्लिक करें → विवरण देखें
- `Ctrl+Click` या `m` → संदर्भ मेनू
- `Ctrl+F` → फ़िल्टर/खोज

### Intercept (इंटरसेप्ट)

**Intercept** टैब अनुरोधों को तुरंत संशोधित करने की अनुमति देता है:

1. **Intercept** बटन क्लिक करें (इंटरसेप्ट सक्रिय करता है)
2. ब्राउज़र में अनुरोध निष्पादित करें
3. अनुरोध Intercept संपादक में दिखाई देगा
4. अनुरोध संशोधित करें
5. **Forward** (भेजें) या **Drop** (छोड़ें) क्लिक करें

**शॉर्टकट कुंजियां:**
- `Ctrl+F` — वर्तमान अनुरोध Forward करें
- `Ctrl+D` — वर्तमान अनुरोध Drop करें
- `Ctrl+I` — Intercept चालू/बंद टॉगल करें

### Match & Replace

नियमों के अनुसार अनुरोधों को स्वचालित रूप से संशोधित करें:

1. Proxy में **M/R** बटन क्लिक करें
2. नियम जोड़ें:
   - **Match:** रेगुलर एक्सप्रेशन
   - **Replace:** प्रतिस्थापन स्ट्रिंग
   - **Target:** Request/Response/Both
   - **Scope:** All/In-scope only
3. नियम सक्षम करें

**उदाहरण:**
- User-Agent बदलें: `User-Agent: .*` → `User-Agent: CustomBot/1.0`
- Header जोड़ें: `$` → `X-Custom: value\r\n` (headers के अंत में)

### Scope

परीक्षण दायरा परिभाषित करें:

1. **Scope** बटन क्लिक करें
2. स्कोप में होस्ट जोड़ें
3. "In-scope only" फ़िल्टर सक्षम करें

**लाभ:**
- केवल लक्ष्य होस्ट का इतिहास फ़िल्टर करें
- पैसिव स्कैनर केवल स्कोप पर काम करता है
- Match/Replace केवल स्कोप पर लागू होता है

## Repeater मॉड्यूल

Repeater HTTP अनुरोधों को बार-बार भेजने और संशोधित करने की अनुमति देता है।

### Repeater में अनुरोध भेजना

**Proxy से:**
1. HTTP History में अनुरोध चुनें
2. `Ctrl+Click` या `m` → **Send to Repeater**

**मैन्युअल निर्माण:**
1. Repeater (`Shift+R`) पर जाएं
2. HTTP अनुरोध मैन्युअल रूप से दर्ज करें

### अनुरोध भेजना

1. बाएं पैनल में अनुरोध संशोधित करें
2. **Send** (`F5`) क्लिक करें
3. दाएं पैनल में प्रतिक्रिया देखें

### टैब

Repeater कई टैब का समर्थन करता है:

- `Ctrl+T` — नया टैब
- `Ctrl+W` — टैब बंद करें
- शीर्षक पर डबल क्लिक — नाम बदलें

### इतिहास

Repeater प्रत्येक टैब में अनुरोध इतिहास सहेजता है:

- **History** बटन → सभी भेजे गए अनुरोधों की सूची
- अनुरोध पर क्लिक करें → इसे लोड करें

## Intruder मॉड्यूल

Intruder Web एप्लिकेशन पर हमलों को स्वचालित करता है।

### हमले के प्रकार

1. **Sniper** — एक payload set, एक स्थिति पर पुनरावृत्ति
2. **Battering Ram** — एक payload सभी स्थितियों पर एक साथ
3. **Pitchfork** — कई payload sets, सिंक्रोनस पुनरावृत्ति
4. **Cluster Bomb** — कई payload sets, सभी संयोजन

### हमले को कॉन्फ़िगर करना

1. **अनुरोध लोड करें:**
   - Proxy/Repeater से Intruder में भेजें
   - या मैन्युअल रूप से दर्ज करें

2. **स्थितियां चिह्नित करें:**
   - पैरामीटर चुनें
   - **Mark Param** या `Ctrl+M` क्लिक करें
   - स्थिति `§value§` के रूप में चिह्नित होगी

3. **Payloads लोड करें:**
   - **Simple List** — मैन्युअल रूप से दर्ज की गई सूची
   - **File** — wordlist लोड करें
   - **Numbers** — संख्या श्रेणी
   - **Brute Force** — वर्णों के सभी संयोजन

4. **विकल्प कॉन्फ़िगर करें:**
   - **Threads** — थ्रेड्स की संख्या (1-50)
   - **Delay** — अनुरोधों के बीच विलंब (ms)
   - **Timeout** — अनुरोध टाइमआउट (s)

5. **हमला शुरू करें:**
   - **Start Attack** (`F5`) क्लिक करें

### परिणामों का विश्लेषण

परिणाम तालिका दिखाती है:
- **#** — अनुरोध संख्या
- **Payload** — उपयोग किया गया payload
- **Status** — प्रतिक्रिया कोड
- **Length** — प्रतिक्रिया आकार
- **Time** — निष्पादन समय

**छँटाई:**
- कॉलम शीर्षक पर क्लिक करें
- विसंगतियां खोजें (अलग Length/Status/Time)

## Scanner मॉड्यूल

Scanner स्वचालित रूप से भेद्यताओं की खोज करता है।

### स्कैनिंग प्रकार

**पैसिव स्कैनिंग:**
- Proxy के माध्यम से ट्रैफ़िक का विश्लेषण करता है
- स्वचालित रूप से सक्षम
- खोजता है: सूचना रिसाव, असुरक्षित headers, Secure/HttpOnly के बिना cookies

**एक्टिव स्कैनिंग:**
- भेद्यताओं की जांच के लिए विशेष अनुरोध भेजता है
- विशिष्ट लक्ष्यों पर मैन्युअल रूप से शुरू किया जाता है

### एक्टिव स्कैनिंग शुरू करना

1. Scanner (`Shift+S`) पर जाएं
2. लक्ष्य **Base URL** दर्ज करें
3. **चेक प्रकार** चुनें:
   - XSS (Reflected, DOM, Stored)
   - SQL Injection
   - SSTI (Template Injection)
   - LFI/Path Traversal
   - RCE (Command Injection)
   - SSRF, XXE, CORS
   - JWT, OAuth भेद्यताएं
4. **पैरामीटर कॉन्फ़िगर करें:**
   - **Depth** — क्रॉल गहराई (1-10)
   - **Max Pages** — अधिकतम पृष्ठ
   - **Threads** — थ्रेड्स की संख्या
5. **Start Scan** (`F5`) क्लिक करें

### खोजें देखना

खोज तालिका दिखाती है:
- **Severity** — गंभीरता (Critical, High, Medium, Low, Info)
- **Type** — भेद्यता प्रकार
- **URL** — कमजोर एंडपॉइंट
- **Parameter** — कमजोर पैरामीटर

**विवरण:**
- खोज पर क्लिक करें → विस्तृत जानकारी
- Proof-of-Concept payload
- सुधार अनुशंसा

### PRO सुविधाएं (लाइसेंस)

- **WAF Detection** — WAF का स्वचालित पता लगाना
- **Smart Payloads** — WAF बायपास के लिए अनुकूली payloads
- **Advanced Checks:** HTTP Smuggling, Deserialization, IDOR
- **AI Analysis** — GPT-4 परिणाम विश्लेषण

## HTTPQL फ़िल्टरिंग

HTTPQL — HTTP इतिहास को फ़िल्टर करने के लिए शक्तिशाली क्वेरी भाषा।

### बुनियादी सिंटैक्स

```
field operator value
```

### समर्थित फ़ील्ड

- `method` — HTTP विधि
- `host` — होस्ट
- `path` — URL पथ
- `status` — स्थिति कोड
- `length` — प्रतिक्रिया आकार
- `time` — निष्पादन समय (ms)

### ऑपरेटर

- `=` — बराबर
- `!=` — बराबर नहीं
- `>`, `<`, `>=`, `<=` — तुलना (संख्याओं के लिए)
- `~` — रेगुलर एक्सप्रेशन
- `contains` — सबस्ट्रिंग शामिल है

### उदाहरण

```
# सभी POST अनुरोध
method = POST

# 4xx/5xx त्रुटियां
status >= 400

# धीमे अनुरोध (>1s)
time > 1000

# विशिष्ट होस्ट
host = example.com

# पथ के लिए regex
path ~ ^/api/

# संयुक्त शर्तें
method = POST AND status = 200

# OR शर्त
status = 404 OR status = 500
```

## टिप्स और ट्रिक्स

### 1. त्वरित नेविगेशन

- मॉड्यूल के बीच स्विच करने के लिए `Shift+अक्षर` का उपयोग करें
- मॉड्यूल के भीतर नेविगेशन के लिए `Tab`/`Shift+Tab`
- त्वरित पहुंच के लिए संदर्भ मेनू (`m` या `Ctrl+Click`)

### 2. Proxy का प्रभावी उपयोग

- गैर-लक्ष्य ट्रैफ़िक को फ़िल्टर करने के लिए Scope कॉन्फ़िगर करें
- स्वचालित संशोधनों के लिए Match & Replace का उपयोग करें
- पृष्ठभूमि विश्लेषण के लिए पैसिव स्कैनर सक्षम करें

### 3. Repeater टिप्स

- विभिन्न एंडपॉइंट के लिए अलग टैब बनाएं
- परिवर्तनों को ट्रैक करने के लिए इतिहास का उपयोग करें
- स्क्रिप्ट में उपयोग के लिए curl कमांड कॉपी करें

### 4. Intruder अनुकूलन

- थ्रेड्स की कम संख्या से शुरू करें (5-10)
- बड़े wordlists के लिए Turbo Mode (PRO) का उपयोग करें
- विसंगतियों की पहचान के लिए Length द्वारा परिणाम सॉर्ट करें

### 5. Scanner कॉन्फ़िगरेशन

- सभी ट्रैफ़िक पर पैसिव स्कैनर शुरू करें
- विशिष्ट एंडपॉइंट पर एक्टिव स्कैनर चलाएं
- खोजों को मैन्युअल रूप से जांचें (गलत सकारात्मक से बचें)

### 6. प्रोजेक्ट

- नियमित रूप से प्रोजेक्ट सहेजें (`Ctrl+S`)
- त्वरित कार्य के लिए .db, विनिमय के लिए JSON का उपयोग करें
- प्रोजेक्ट में सभी इतिहास और परिणाम शामिल हैं

## समस्या निवारण

### Proxy HTTPS इंटरसेप्ट नहीं कर रहा

- जांचें कि CA प्रमाणपत्र इंस्टॉल है या नहीं
- Firefox में: सुनिश्चित करें कि प्रमाणपत्र विश्वसनीय है
- ब्राउज़र में प्रॉक्सी सेटिंग्स जांचें

### इंटरफ़ेस धीमा है

- अनावश्यक मॉड्यूल बंद करें
- इतिहास साफ़ करें
- Intruder/Scanner में थ्रेड्स की संख्या कम करें

### Scanner भेद्यताएं नहीं खोज रहा

- जांचें कि लक्ष्य Scope में है या नहीं
- सुनिश्चित करें कि आवश्यक चेक प्रकार चुने गए हैं
- कुछ भेद्यताओं के लिए PRO लाइसेंस की आवश्यकता है
