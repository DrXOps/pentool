# 🚀 Первый запуск — сертификат и первый перехват

Минимальная инструкция от `pip install pentool` до первого перехваченного
HTTPS-запроса. Полная картина — в [Быстром старте](QUICKSTART.md) и
[Руководстве пользователя](USER_GUIDE.md).

> ⚠️ **Используйте современный терминал.** TUI Pentool построен на Textual и
> опирается на поддержку мыши, true color и современный рендеринг.
> Стандартный `cmd.exe` в Windows и старые/легаси терминалы будут
> отображаться некорректно. Рекомендуется: **Windows Terminal**, **iTerm2**
> (macOS), **GNOME Terminal/Kitty/Alacritty/WezTerm** (Linux). На Windows
> лучше всего запускать Pentool внутри **WSL**.

---

## 1. Установка и запуск

```bash
pip install pentool
pentool
```

Откроется экран Dashboard.

## 2. Запустите прокси

1. Перейдите в модуль **Proxy** (`Ctrl+X` → Proxy, или `Shift+P`)
2. Нажмите **"○ Proxy"**, чтобы запустить — кнопка сменится на
   **"● Proxy :8080"** (порт/хост по умолчанию `127.0.0.1:8080`, меняется в
   настройках)

## 3. Скачайте и установите CA-сертификат

При первом запуске прокси Pentool генерирует локальный корневой
сертификат (CA), чтобы расшифровывать HTTPS-трафик (тот же подход, что и в
Burp/mitmproxy). Ничего не покидает вашу машину — CA генерируется локально в
`~/.config/pentool/certs/ca.crt`.

1. На экране Proxy нажмите **"Install CA cert"** (или откройте через
   **Settings → Proxy → Install CA cert**) — появится диалог с путём к
   сертификату и пошаговыми инструкциями для Firefox, Chrome и системной
   установки (Ubuntu/Debian, Fedora/RHEL).
2. Следуйте инструкции для вашего браузера:
   - **Firefox:** `about:preferences#privacy` → Сертификаты → Просмотр
     сертификатов → вкладка **Центры сертификации** (не "Ваши сертификаты")
     → Импорт → выберите `ca.crt` → отметьте "Доверять этому ЦС при
     идентификации веб-сайтов" → перезапустите Firefox.
   - **Chrome/Chromium:** `chrome://settings/certificates` → Центры
     сертификации → Импорт → выберите `ca.crt` → отметьте "Доверять для
     идентификации веб-сайтов" → перезапустите Chrome.
   - **Системно (Linux):** команды показаны прямо в диалоге для вашего
     дистрибутива.
3. **Настройте прокси в браузере** на Pentool:
   - HTTP/HTTPS прокси: `127.0.0.1`, порт `8080` (или тот, что вы задали)
   - Firefox: Настройки → Настройки сети → Ручная настройка прокси
   - Chrome: запустите с `--proxy-server="127.0.0.1:8080"`, либо используйте
     системный прокси или расширение вроде FoxyProxy

## 4. Перехватите первый запрос

1. На экране Proxy включите **"○ Intercept"**
2. Откройте любой HTTPS-сайт в настроенном браузере
3. Запрос остановится во вкладке **Intercept** Pentool — просмотрите/
   отредактируйте его, затем **Forward** (переслать) или **Drop** (сбросить)
4. Выключите Intercept обратно, чтобы трафик шёл свободно — он будет
   накапливаться в **HTTP History**

Готово — вы перехватываете трафик и теперь можете отправлять запросы в
**Repeater**, **Intruder**, или запускать **Scanner** по ним.
