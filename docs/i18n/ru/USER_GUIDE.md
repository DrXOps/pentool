## Начало работы

### Первый запуск

```bash
pentool
```

Основной интерфейс состоит из:
- **Верхняя панель** — навигационное меню и статус
- **Основная область** — экран текущего модуля
- **Статус-бар** — статус подключения, горячие клавиши

### Навигация

- `Ctrl+X` — Открыть меню
- `Tab` / `Shift+Tab` — Переключение между виджетами
- `Ctrl+Q` — Выход
- Стрелки — Навигация по спискам

## Модуль Proxy

Proxy перехватывает HTTP/HTTPS трафик между вашим браузером и целью.

### Запуск Proxy

1. Перейдите в Proxy (`Shift+P`)
2. Нажмите кнопку **Start Proxy**
3. По умолчанию слушает на `127.0.0.1:8888`

### Настройка браузера

**Firefox:**
- Settings → Network → Manual proxy configuration
- HTTP Proxy: `127.0.0.1` Port: `8888`
- Включите "Also use this proxy for HTTPS"

**Chrome/Chromium:**
- Используйте расширение (FoxyProxy) или системные настройки

### HTTP History

Вкладка **HTTP History** показывает все перехваченные запросы:

- **ID** — уникальный номер запроса
- **Host** — целевой хост
- **Method** — HTTP метод (GET, POST, etc.)
- **URL** — путь запроса
- **Status** — код ответа
- **Size** — размер ответа
- **Time** — время выполнения

**Действия:**
- Клик на запросе → просмотр деталей
- `Ctrl+Click` или `m` → контекстное меню
- `Ctrl+F` → фильтр/поиск

### Intercept (Перехват)

Вкладка **Intercept** позволяет модифицировать запросы на лету:

1. Нажмите кнопку **Intercept** (активирует перехват)
2. Выполните запрос в браузере
3. Запрос появится в Intercept editor
4. Модифицируйте запрос
5. Нажмите **Forward** (отправить) или **Drop** (отбросить)

**Горячие клавиши:**
- `Ctrl+F` — Forward текущий запрос
- `Ctrl+D` — Drop текущий запрос
- `Ctrl+I` — Toggle Intercept on/off

### Match & Replace

Автоматически модифицируйте запросы по правилам:

1. Нажмите кнопку **M/R** в Proxy
2. Добавьте правило:
   - **Match:** регулярное выражение
   - **Replace:** строка замены
   - **Target:** Request/Response/Both
   - **Scope:** All/In-scope only
3. Включите правило

**Примеры:**
- Изменить User-Agent: `User-Agent: .*` → `User-Agent: CustomBot/1.0`
- Добавить header: `$` → `X-Custom: value\r\n` (в конце headers)

### Scope

Определите область тестирования:

1. Нажмите кнопку **Scope**
2. Добавьте хосты в scope
3. Включите "In-scope only" filter

**Преимущества:**
- Фильтрация истории только целевых хостов
- Пассивный сканер работает только на scope
- Match/Replace применяется только на scope

## Модуль Repeater

Repeater позволяет многократно отправлять и модифицировать HTTP запросы.

### Отправка запроса в Repeater

**Из Proxy:**
1. Выберите запрос в HTTP History
2. `Ctrl+Click` или `m` → **Send to Repeater**

**Ручное создание:**
1. Перейдите в Repeater (`Shift+R`)
2. Введите HTTP запрос вручную

### Отправка запроса

1. Модифицируйте запрос в левой панели
2. Нажмите **Send** (`F5`)
3. Просмотрите ответ в правой панели

### Вкладки

Repeater поддерживает несколько вкладок:

- `Ctrl+T` — новая вкладка
- `Ctrl+W` — закрыть вкладку
- Двойной клик на названии — переименовать

### История

Repeater сохраняет историю запросов в каждой вкладке:

- Кнопка **History** → список всех отправленных запросов
- Клик на запросе → загрузить его

## Модуль Intruder

Intruder автоматизирует атаки на веб-приложения.

### Типы атак

1. **Sniper** — один payload set, перебор по одной позиции
2. **Battering Ram** — один payload во все позиции одновременно
3. **Pitchfork** — несколько payload sets, синхронная итерация
4. **Cluster Bomb** — несколько payload sets, все комбинации

### Настройка атаки

1. **Загрузите запрос:**
   - Send to Intruder из Proxy/Repeater
   - Или введите вручную

2. **Отметьте позиции:**
   - Выделите параметр
   - Нажмите **Mark Param** или `Ctrl+M`
   - Позиция будет помечена как `§value§`

3. **Загрузите payloads:**
   - **Simple List** — вручную введённый список
   - **File** — загрузить wordlist
   - **Numbers** — диапазон чисел
   - **Brute Force** — все комбинации символов

4. **Настройте опции:**
   - **Threads** — количество потоков (1-50)
   - **Delay** — задержка между запросами (ms)
   - **Timeout** — таймаут запроса (s)

5. **Запустите атаку:**
   - Нажмите **Start Attack** (`F5`)

### Анализ результатов

Таблица результатов показывает:
- **#** — номер запроса
- **Payload** — использованный payload
- **Status** — код ответа
- **Length** — размер ответа
- **Time** — время выполнения

**Сортировка:**
- Клик на заголовке колонки
- Ищите аномалии (отличающиеся Length/Status/Time)

**Grep/Extract:**
- Настройте регулярные выражения для извлечения данных из ответов

## Модуль Scanner

Scanner автоматически обнаруживает уязвимости.

### Типы сканирования

**Passive Scanning:**
- Анализирует трафик через Proxy
- Включается автоматически
- Находит: информационные утечки, небезопасные заголовки, cookies без Secure/HttpOnly

**Active Scanning:**
- Отправляет специальные запросы для проверки уязвимостей
- Запускается вручную на конкретные цели

### Запуск активного сканирования

1. Перейдите в Scanner (`Shift+S`)
2. Введите **Base URL** цели
3. Выберите **типы проверок:**
   - XSS (Reflected, DOM, Stored)
   - SQL Injection
   - SSTI (Template Injection)
   - LFI/Path Traversal
   - RCE (Command Injection)
   - SSRF, XXE, CORS
   - JWT, OAuth vulnerabilities
4. Настройте **параметры:**
   - **Depth** — глубина обхода (1-10)
   - **Max Pages** — максимум страниц
   - **Threads** — количество потоков
5. Нажмите **Start Scan** (`F5`)

### Просмотр findings

Таблица findings показывает:
- **Severity** — критичность (Critical, High, Medium, Low, Info)
- **Type** — тип уязвимости
- **URL** — уязвимый endpoint
- **Parameter** — уязвимый параметр

**Детали:**
- Клик на finding → детальная информация
- Proof-of-Concept payload
- Recommendation по исправлению

### PRO функции (лицензия)

- **WAF Detection** — автоматическое определение WAF
- **Smart Payloads** — адаптивные payloads под WAF bypass
- **Advanced Checks:** HTTP Smuggling, Deserialization, IDOR
- **AI Analysis** — GPT-4 анализ результатов

## Модуль Decoder

Decoder кодирует/декодирует данные в различных форматах.

### Поддерживаемые операции

**Encoding:**
- URL encode
- HTML encode
- Base64 encode
- Hex encode

**Decoding:**
- URL decode
- HTML decode
- Base64 decode
- Hex decode

**Hashing:**
- MD5, SHA-1, SHA-256, SHA-512

**Compression:**
- Gzip compress/decompress

**Special:**
- JWT decode
- Unicode escape/unescape

### Smart Decode

Нажмите **Smart Decode** — автоматическое определение и декодирование:

- Пытается несколько методов декодирования
- Показывает результат наиболее вероятного формата

### Chain Mode

Применяйте несколько операций последовательно:

1. Введите данные
2. Выберите операцию 1 → Apply
3. Выберите операцию 2 → Apply
4. Результат каждой операции становится входом следующей

## Модуль Comparer

Comparer сравнивает два текста и показывает различия.

### Использование

1. Перейдите в Comparer (`Shift+C`)
2. Вставьте **Text 1** в левую панель
3. Вставьте **Text 2** в правую панель
4. Нажмите **Compare** (`F5`)

### Режимы сравнения

- **Words** — пословное сравнение
- **Lines** — построчное сравнение (по умолчанию)
- **Bytes** — побайтовое сравнение

### Результат

- Зелёный — строки только в Text 1
- Красный — строки только в Text 2
- Белый — идентичные строки

**Статистика:**
- Identical lines — одинаковых строк
- Modified lines — изменённых строк
- Added lines — добавленных строк

## Модуль Spider

Spider автоматически обходит веб-приложение и строит карту.

### Запуск Spider

1. Перейдите в Spider (`Shift+W`)
2. Введите **Base URL**
3. Настройте параметры:
   - **Max Depth** — максимальная глубина обхода
   - **Max Pages** — максимум страниц для обхода
   - **Threads** — количество потоков
4. Нажмите **Start** (`F5`)

### Результаты

Spider собирает:
- **Pages** — обнаруженные страницы
- **Forms** — найденные формы
- **Endpoints** — API endpoints
- **Parameters** — параметры запросов

**Действия:**
- Найденные URL отправляются в Target sitemap
- Можно отправить результаты в Scanner для проверки

## Фильтрация HTTPQL

HTTPQL — мощный язык запросов для фильтрации HTTP истории.

### Базовый синтаксис

```
field operator value
```

### Поддерживаемые поля

- `method` — HTTP метод
- `host` — хост
- `path` — путь URL
- `status` — код статуса
- `length` — размер ответа
- `time` — время выполнения (ms)

### Операторы

- `=` — равно
- `!=` — не равно
- `>`, `<`, `>=`, `<=` — сравнение (для чисел)
- `~` — регулярное выражение
- `contains` — содержит подстроку

### Примеры

```
# Все POST запросы
method = POST

# Ошибки 4xx/5xx
status >= 400

# Медленные запросы (>1s)
time > 1000

# Определённый хост
host = example.com

# Regex по пути
path ~ ^/api/

# Комбинированные условия
method = POST AND status = 200

# OR условие
status = 404 OR status = 500
```

## Советы и трюки

### 1. Быстрая навигация

- Используйте `Shift+буква` для переключения между модулями
- `Tab`/`Shift+Tab` для навигации внутри модуля
- Контекстное меню (`m` или `Ctrl+Click`) для быстрого доступа

### 2. Эффективное использование Proxy

- Настройте Scope для фильтрации нецелевого трафика
- Используйте Match & Replace для автоматических модификаций
- Включите Passive Scanner для фонового анализа

### 3. Repeater tips

- Создавайте отдельные вкладки для разных endpoints
- Используйте историю для отслеживания изменений
- Копируйте curl команды для использования в скриптах

### 4. Intruder оптимизация

- Начинайте с малого числа потоков (5-10)
- Для больших wordlists используйте Turbo Mode (PRO)
- Сортируйте результаты по Length для выявления аномалий

### 5. Scanner настройка

- Начинайте с Passive Scanner на весь трафик
- Запускайте Active Scanner на конкретные endpoints
- Проверяйте findings вручную (избегайте false positives)

### 6. Проекты

- Сохраняйте проекты регулярно (`Ctrl+S`)
- Используйте .db для быстрой работы, JSON для обмена
- Проекты включают всю историю и результаты

### 7. Performance

- Закрывайте ненужные вкладки в Repeater/Intruder
- Очищайте Proxy history периодически
- Используйте фильтры для работы с большими наборами данных

## Устранение неполадок

### Proxy не перехватывает HTTPS

- Проверьте, установлен ли CA сертификат
- В Firefox: убедитесь что сертификат доверенный
- Проверьте настройки прокси в браузере

### Интерфейс тормозит

- Закройте ненужные модули
- Очистите историю
- Уменьшите количество потоков в Intruder/Scanner

### Scanner не находит уязвимости

- Проверьте, что цель в Scope
- Убедитесь что выбраны нужные типы проверок
- Некоторые уязвимости требуют PRO лицензии
