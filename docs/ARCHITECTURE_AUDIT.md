#### 4.1 Scanner Checks (детальный анализ)

**Найдено 23 checks:**
- XSS (Reflected, DOM, Stored)
- SQLi (Union-based, Error-based, Boolean-based)
- SSTI (Template Injection)
- LFI/Path Traversal
- RCE (Command Injection)
- SSRF
- XXE
- NoSQL Injection
- CORS
- JWT vulnerabilities
- OAuth misconfigurations
- Header Injection
- Open Redirect
- Sensitive Data Exposure

**Архитектура checks:**
✅ **Хорошо:** Единый паттерн через `BaseCheck`
✅ **Хорошо:** Переиспользуемые хелперы в `helpers.py`
✅ **Хорошо:** Context-aware detection (XSS)

**Проверка XSS check (xss.py):**
- ✅ **Reflected XSS:** обнаруживается через маркеры
- ✅ **Context detection:** 11 типов контекстов (JS, HTML attr, body)
- ✅ **Filter probing:** автоматическое обнаружение фильтров
- ✅ **HTML entity normalization:** корректная обработка &apos; и т.д.
- ✅ **False positive filtering:** есть проверка is_valid_xss_finding()
- ⚠️ **DOM XSS:** отдельный check (dom_xss.py) — нужна интеграция

**Оценка True Positive rate:** Высокая (на основе кода)
**Оценка False Positive rate:** Средняя (есть фильтрация, но можно улучшить)

**Рекомендации для XSS:**
1. Добавить больше bypass-техник для WAF
2. Интегрировать DOM XSS анализ в основной check
3. Расширить тесты (проверить на OWASP XSS test suite)

## УНИВЕРСАЛЬНОСТЬ КОДА

### Хорошие паттерны

✅ **BaseCheck для scanner checks:**
```python
class XSSCheck(BaseCheck):
    async def run(self, request, http_client):
        ...
```
Все checks используют единый интерфейс — отлично!

✅ **Хелперы для точек инъекции:**
```python
# helpers.py
await test_get_params(...)
await test_post_urlencoded(...)
await test_json_body(...)
await test_cookie_params(...)
await test_header_params(...)
await test_path_segments(...)
```
Переиспользуемые функции для всех checks — отлично!

✅ **EventBus для коммуникации:**
Слабосвязанная архитектура — подходит для SaaS.

### Проблемные места

⚠️ **HTTP клиент создаётся в разных местах:**
- ScanService создаёт свой HTTPClient
- Checks создают свой
- → Нужен singleton или dependency injection

⚠️ **Конфигурация разбросана:**
- Config в core/
- Лимиты в лицензии
- Настройки в TUI
- → Нужна единая точка

**Рекомендации:**
1. HTTPClient через DI (передавать в конструктор)
2. Централизованная конфигурация

**Приоритет:** 🟡 СРЕДНИЙ
