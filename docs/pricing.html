// activation

After the key arrives

01 / activate

Enter the key

Open Pentool → Settings → License, paste the key, press Activate. The first activation occupies one slot and binds it to this machine.

02 / more machines

Use your slots

Activate the same key on another machine — it takes the next free slot. When all slots are used, further machines are refused with the count shown.

03 / offline

Works without network

The licence is validated online at startup and cached. Without network Pentool keeps working with PRO features for the grace period, then asks to reconnect.

04 / transfer

Moving to a new machine?

Deactivate on the old machine (frees the slot), or ask support to reassign it — the old binding is released and the new machine takes its place.

# activate from the command line (same as Settings → License)
$ pentool license activate PTOOL-XXXX-XXXX-XXXX

# 14-day trial, no card required
$ pentool license trial

# release this machine's slot
$ pentool license deactivate
// faq

Frequently asked questions

Does the free version have usage restrictions?

+
No. The free core is open source under AGPL-3.0: you may use it commercially, modify it and redistribute it under the same licence. PRO is an optional add-on — the tool works without it.

What exactly does PRO unlock?

+
Vulnerability scanner (21 checks, active + passive), Reconnaissance (subdomains, endpoints, real IP behind CDN, parameter fuzzing), AI analysis of findings, Smart Payloads and PRO payload sets, HTML reports, Turbo Intruder. The table above is the complete list.

Is there a Team plan?

+
There is no separate Team plan. If several people need the tool, buy a PRO key with enough slots: each slot is one machine, and any number of people can use those machines.

How do slots work?

+
A key has a fixed number of slots (chosen at purchase). Each machine you activate on occupies one slot. Deactivating on a machine frees its slot for another machine.

What happens when the licence expires?

+
PRO features stop working; the free part of the tool keeps running. You get a warning before expiry and can renew — the key and its slots stay the same.

Does Pentool phone home constantly?

+
No. The licence is validated at startup and cached; the only identifiers sent are the key and a hashed machine id. Crash reports are opt-out and contain a traceback, version and OS — never your traffic. Details in the privacy policy.

Refund policy?

+
Full refund within 14 days of purchase, no questions asked — write to support@pentool.pro with the key. Refund frees the slots and disables the key.

Is there a trial for PRO?

+
Yes — run pentool license trial for a 14-day trial, no card required.
