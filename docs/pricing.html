How licensing works

01 / purchase

Buy a license key

Email us or use the button above. You'll receive a key in the format PTOOL-XXXX-XXXX-XXXX within minutes.

02 / activate

Enter in Settings

Open Pentool → Settings → License tab. Paste your key and click Activate. The key binds to your machine ID on first activation.

03 / verify

Online validation

Pentool validates against license.pentool.pro/api/validate on startup. Works offline for up to 7 days (grace period).

04 / transfer

Need to move machines?

Email support@pentool.pro to reset machine binding. We'll handle it within 24 h.

# CLI activation (alternative)
$ pentool --activate PTOOL-XXXX-XXXX-XXXX

# Check current license status
$ pentool --license-info

Frequently asked questions

Does the free version have any restrictions on usage?

+
No. The free version is fully open source (MIT). You can use it commercially, modify it, and redistribute it. PRO features are optional add-ons.

What happens when my license expires?

+
PRO features become unavailable, but the core tool continues to work. You'll get a warning 30 days before expiry. Renew at the same price.

Can I use one key on multiple machines?

+
PRO keys bind to a single machine on first activation. Team keys support up to 5 machines simultaneously. Contact us for enterprise multi-seat licensing.

Does Pentool phone home constantly?

+
No. Validation happens once at startup and caches the result for 24 hours. The only data sent is your license key and a machine ID hash — no usage telemetry.

Is there a trial for PRO?

+
Yes — email us and we'll issue a 14-day trial key. No card required.

Refund policy?

+
Full refund within 14 days of purchase, no questions asked. Email support@pentool.pro with your key.
