Successfully installed pentool-0.1.1

$ pentool
▶ Dashboard | Proxy | Scanner | Intruder | Repeater | Tools

# Or use CLI mode
$ pentool scan active --url https://example.com

[✓] SQLi found: /search?q=
[✓] XSS found: /comment?body=
What's inside

Everything you need for web pentesting

Modular architecture — use what you need, extend what you want.

🌐

Proxy

Intercept and modify HTTP/HTTPS traffic in real time. Match & Replace rules, WebSocket support, scope management.

🔄

Repeater

Replay and tweak requests instantly. Save tabs between sessions, switch scenarios with one keystroke.

💥

Intruder

4 attack modes: Sniper, Battering Ram, Pitchfork, Cluster Bomb. Turbo Mode via Keep-Alive for 10× speed.

🔍

ScannerPRO

SQLi, XSS, SSTI, LFI, RCE, SSRF, XXE, CORS, JWT — context-aware payloads, WAF bypass, blind techniques.

🕷

Spider

Auto-crawl pages, forms, API endpoints, JS files. JavaScript rendering via Playwright.

🎯

Target / Site Map

Build a visual site map from proxy traffic. Manage scope and filter hosts without leaving the UI.

🔐

Decoder

19 encode/decode/hash operations. Chain them together for complex transformations.

📊

Comparer

Side-by-side diff with change highlighting. Spot differences between responses instantly.

🎲

SequencerPRO

Entropy analysis of tokens — sessions, CSRF, JWT. FIPS statistical tests included.

🧩

Plugin System

Extend without touching core. PRO plugins add advanced scanners, smart payloads, report generators.

⚡

Async Core

Fully async engine. Thousands of concurrent connections, hundreds of requests per second.

🆓

Open Source

Base version is free and open (AGPL-3.0). PRO extensions coming soon — trial available now.
