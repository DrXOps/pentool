Pentool is a fully async, keyboard-driven TUI for web security testing — hundreds of concurrent requests, zero Java, zero Electron.

📦 uv tool install pentool ⭐ GitHub 💬 Get PRO Trial
bash — pentool
# Install (recommended — isolated, fast)
$ uv tool install pentool
Resolved 12 packages in 0.3s — Installed pentool-0.2.11

# Launch TUI
$ pentool
▶ Dashboard | Proxy | Scanner | Intruder | Repeater | Tools

# Or use CLI mode
$ pentool scan active --url https://example.com
[~] Scanning https://example.com ...
[✓] SQLi found: /search?q=
[✓] XSS found: /comment?body=
Why Pentool

What competitors don't offer

No Java. No Electron. No browser tab eating your RAM. Just a fast async TUI that stays out of your way.

⚡

Fully Async Engine

Built on asyncio from the ground up — thousands of concurrent connections, hundreds of req/s. Burp queues. Pentool flies.

⌨️

Keyboard-First TUI

Every action reachable without a mouse. Works over SSH, in tmux, on headless servers — anywhere a terminal runs.

💥

Intruder Turbo Mode

Keep-Alive + connection pooling = 10× attack speed vs. standard HTTP. Four modes: Sniper, Battering Ram, Pitchfork, Cluster Bomb.

🔍

Smart ScannerPRO

Context-aware payloads for SQLi, XSS, SSTI, LFI, RCE, SSRF, XXE, CORS, JWT. WAF bypass and blind techniques built in.

🌐

Proxy + WebSockets

Intercept HTTP/HTTPS and WebSocket frames in real time. Match & Replace rules, scope filters, history search.

🔐

Decoder · Comparer · Sequencer

19 chained encode/decode/hash ops. Side-by-side diff. Entropy + FIPS analysis for sessions, CSRF tokens, JWTs.

📦

uv tool install — done

One command, no Docker, no JDK, no license server. Linux, macOS, Windows WSL. Python 3.10+.

🧩

Plugin API

Extend without touching core. PRO plugins add advanced scanners, smart payloads, and report generators.

One-line setup

Get started in seconds

Works on Linux, macOS, and Windows (WSL). Python 3.10+.

$ uv tool install pentool copy
$ pentool copy
