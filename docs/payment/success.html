Payment received

Thank you. The key is sent to the e-mail given at checkout — usually within a few minutes. If it is not there, check the spam folder.

01

Find the key in the letter

The letter contains a key like PTOOL-XXXX-XXXX-XXXX and the number of slots you bought.

02

Activate it in the app

Pentool → Settings → License → Activate. The first activation takes a slot and binds it to this machine.

03

If the letter is missing

Write to support@pentool.pro with the order number and the e-mail used for payment — we will issue the key by hand.
