Веб-пентест в одном окне терминала

Перехват и повтор запросов, атаки по словарям, сканер уязвимостей, разведка и отчёты. Один проект вместо десятка окон, браузера и тяжёлых IDE.

Зачем это

Меньше переключений — больше работы

Pentool не пытается заменить весь ваш набор инструментов. Он убирает суету между ними: цель, запросы, находки и отчёт лежат в одном проекте.

Цель — одна команда

pentool --url https://target создаёт проект, добавляет цель и поднимает прокси. Дальше вы сразу видите запросы в истории.

Работает по SSH

Терминал, tmux, сервер без графики. Клавиатура и мышь, тёмная и светлая темы — ничего не нужно дорисовывать.

Проект — это папка

История трафика, находки и отчёты лежат в SQLite рядом с проектом: можно вернуться через месяц или передать коллеге.

Отчёты, а не скриншоты

Находки выгружаются в HTML, JSON или CSV, отдельно — сводный отчёт в шаблоне Bug Bounty и экспорт в HackerOne, Bugcrowd и DefectDojo.

Модули

Десять вкладок — десять задач

Переключение по хоткею, состояние вкладок сохраняется между запусками. Сканер и разведка открываются по ключу PRO, остальное доступно сразу.

Dashboard

Сводка по проекту: что найдено, что запущено, быстрые действия.

Proxy

Перехват HTTP/HTTPS и WebSocket, история запросов, правила Match & Replace, scope.

Repeater

Правка и повтор запросов во вкладках, сравнение с предыдущим ответом.

Intruder

Sniper, Battering Ram, Pitchfork, Cluster Bomb. Свои лимиты потоков и задержки, результаты в таблице.

ScannerPRO

Активные и пассивные проверки: SQLi, XSS, SSTI, LFI, RCE, SSRF, XXE и другие.

Target

Карта сайта из трафика прокси, правила scope, фильтры по хостам.

Utils

Decoder (19 операций в цепочках), Comparer (построчный diff), Sequencer (энтропия и FIPS).

Extensions

Плагины: свои экраны, проверки сканера, пассивные проверки и команды.

ReconPRO

Субдомены, эндпоинты, реальный IP за CDN, фаззинг параметров.

Settings

Темы, сеть, прокси, лицензия, локальный ИИ.

У Decoder, Comparer и Sequencer — свои подвкладки внутри Utils.

Сканер · PRO

Что именно проверяется

Активные проверки отправляют запросы к цели и подтверждают находку, пассивные — разбирают ответы, которые и так идут через прокси.

  • Инъекции: SQLi (error-, time- и boolean-based, UNION), NoSQL, SSTI, LFI, path traversal, RCE, header и host header injection
  • Клиентская сторона: XSS, DOM XSS, prototype pollution, open redirect
  • Доступ и данные: broken auth, JWT none, OAuth, CORS, чувствительные данные в ответах
  • Сервисы: SSRF, XXE, GraphQL
  • Пассивно: отсутствующие заголовки безопасности, утечки информации, чувствительные данные, DOM XSS

Найденное складывается в таблицу с уровнем риска, доказательством и запросом, который можно повторить в Repeater. Отчёт — HTML, JSON или CSV, сводный — в шаблоне Bug Bounty.

Список проверок растёт от версии к версии. Если нужной нет — плагин может добавить свою.

Искусственный интеллект

Модель работает у вас, а не в облаке

ИИ в Pentool — небольшая локальная модель. Она запускается на вашем процессоре, по умолчанию выключена и ничего не отправляет наружу.

Что делает

Подбирает проверки под технологию цели, генерирует payload'ы, пробует обойти WAF для XSS, перепроверяет находки и предлагает эндпоинты при обходе.

Где работает

На вашей машине: модель весом около 350 МБ скачивается один раз, считает на CPU, видеокарта не нужна.

Что не уходит

Запросы, ответы и находки остаются в проекте. Облачного провайдера в Pentool нет — отправлять трафик просто некуда.

Когда включать

По желанию: в Settings → AI. Без модели работают обычные проверки, а разбор находок идёт по простым эвристикам.

ИИ — помощник, а не замена проверкам: окончательное решение по находке остаётся за вами.

Автоматизация

Сканирование в пайплайне

Тот же сканер запускается без интерфейса — флагом --headless. Подходит для GitHub Actions, GitLab CI и любого шелла.

bash
$ pentool --url https://example.com --headless \
--check xss,sqli --threads 20 --delay 0.2 \
--format html --output report.html
# код возврата: 0 — успех, 1 — сбой скана, 2 — неверные аргументы

Есть и другие флаги: --crawl --depth, --ai, --format json.

Свои проверки оформляются плагином: BasePlugin умеет добавлять экран, команду CLI, проверку сканера и пассивную проверку. Плагины лежат в ~/.config/pentool/plugins, API документирован.

Установка

Две команды до первого запроса

Пакет ставится из PyPI. Docker, JDK и внешний прокси не нужны.

bash
$ uv tool install pentool
$ pentool --url https://example.com
▶ Dashboard · Proxy · Repeater · Intruder · Scanner · Target · Utils · Extensions · Recon · Settings

Без uv подойдёт pip install pentool. Сертификат для HTTPS Pentool создаёт сам.

Нужен современный терминал: Windows Terminal, iTerm2, GNOME Terminal, Kitty, Alacritty или WezTerm. На Windows удобнее WSL2.
