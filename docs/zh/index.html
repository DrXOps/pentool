面向终端的渗透测试工具

在一个终端窗口里完成 Web 渗透测试

拦截并重放请求、按字典发起攻击、扫描漏洞、做侦察并出报告。一个项目，替代十几个窗口、一个浏览器和笨重的 IDE。

为什么需要它

少切换几次，多做一些工作

Pentool 并不想取代你整套工具链。它去掉的是工具之间的来回折腾：目标、请求、发现和报告都放在同一个项目里。

目标只需一条命令

pentool --url https://target 会创建项目、添加目标并启动代理。接下来请求直接出现在历史里。

通过 SSH 使用

终端、tmux、没有图形界面的服务器。键盘和鼠标、深色和浅色主题——客户端不需要额外配置。

项目就是一个文件夹

流量历史、发现和报告存放在项目旁边的 SQLite 里：可以过一个月再回来，也可以交给同事。

要的是报告，不是截图

发现可以导出为 HTML、JSON 或 CSV，另外还有 Bug Bounty 模板的汇总报告，以及导出到 HackerOne、Bugcrowd 和 DefectDojo。

模块

十个标签页，十项任务

用快捷键切换，标签页状态在重启后保留。扫描器和侦察需要 PRO 密钥，其余功能立即可以使用。

Dashboard

项目概览：发现了什么、正在运行什么、快捷操作。

Proxy

HTTP/HTTPS 和 WebSocket 拦截、请求历史、Match & Replace 规则、scope。

Repeater

在标签页里修改并重放请求，与上一次响应做对比。

Intruder

Sniper、Battering Ram、Pitchfork、Cluster Bomb。线程数和延迟可以自定，结果以表格呈现。

ScannerPRO

主动和被动检查：SQLi、XSS、SSTI、LFI、RCE、SSRF、XXE 等。

Target

从代理流量生成站点地图、scope 规则、按主机过滤。

Utils

Decoder（19 种链式操作）、Comparer（逐行 diff）、Sequencer（熵和 FIPS 测试）。

Extensions

插件：自定义界面、扫描器检查、被动检查和命令。

ReconPRO

子域名、端点、CDN 背后的真实 IP、参数模糊测试。

Settings

主题、网络、代理、许可证、本地 AI。

Decoder、Comparer 和 Sequencer 在 Utils 里有各自的子标签页。

扫描器 · PRO

具体检查什么

主动检查会向目标发送请求并确认发现，被动检查则分析本来就会经过代理的响应。

  • 注入： SQLi（error、time 和 boolean 型，UNION）、NoSQL、SSTI、LFI、路径穿越、RCE、header 和 host header 注入
  • 客户端： XSS、DOM XSS、原型链污染、开放重定向
  • 访问与数据： 认证缺陷、JWT none、OAuth、CORS、响应中的敏感数据
  • 服务： SSRF、XXE、GraphQL
  • 被动： 缺失的安全响应头、信息泄露、敏感数据、DOM XSS

发现会进入一张带风险等级、证据和原始请求的表格，请求可以直接在 Repeater 里重放。报告可导出为 HTML、JSON 或 CSV，汇总报告使用 Bug Bounty 模板。

检查列表会随版本增加。如果缺了你需要的那一项，插件可以自己加一个。

人工智能

模型跑在你的机器上，不在云端

Pentool 里的 AI 是一个小型本地模型。它运行在你的 CPU 上，默认关闭，不向外部发送任何内容。

它做什么

按目标的技术栈挑选检查、生成 payload、尝试为 XSS 绕过 WAF、复核发现，并在爬取过程中建议端点。

它跑在哪

在你的机器上：约 350 MB 的模型只需下载一次，用 CPU 推理，不需要显卡。

什么不会外发

请求、响应和发现都留在项目里。Pentool 没有云端服务商——流量根本没有地方可发。

什么时候打开

可选：在 Settings → AI 里。不开模型时常规检查照常工作，发现分析会退回简单的启发式规则。

AI 是助手，不能替代检查：对发现的最终判断仍在你手上。

自动化

在流水线里扫描

同一个扫描器可以不带界面运行——用 --headless 标志。适用于 GitHub Actions、GitLab CI 和任何 shell。

bash
$ pentool --url https://example.com --headless \
--check xss,sqli --threads 20 --delay 0.2 \
--format html --output report.html
# 退出码：0 — 成功，1 — 扫描失败，2 — 参数错误

还有其他标志：--crawl --depth、--ai、--format json。

自定义检查以插件形式提供：BasePlugin 可以添加界面、CLI 命令、扫描器检查和被动检查。插件放在 ~/.config/pentool/plugins，API 有文档。

安装

两条命令，直到发出第一个请求

软件包从 PyPI 安装。不需要 Docker、JDK 和外部代理。

bash
$ uv tool install pentool
$ pentool --url https://example.com
▶ Dashboard · Proxy · Repeater · Intruder · Scanner · Target · Utils · Extensions · Recon · Settings

没有 uv 也可以用 pip install pentool。HTTPS 证书 Pentool 会自己生成。

需要现代终端：Windows Terminal、iTerm2、GNOME Terminal、Kitty、Alacritty 或 WezTerm。在 Windows 上 WSL2 更省事。
