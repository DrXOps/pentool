## 2. Что сделано по итерациям

Итерации D0–D7 из ТЗ; часть работ осталась за границей этой ветки и
перечислена в §5.

### D0 — composition root и слои
- `PentoolApp` остаётся единственной точкой сборки (ADR-1, ADR-4).
- TUI перестал импортировать `modules`: `auto_scope._tech_detect_and_cache`
  теперь зовёт `services.tech_detector.run_fingerprint` /
  `fingerprint_from_html` / `cache_tech_profile` (F-003).
- `tools/check_layers.py` — 148 файлов, 0 нарушений.

### D1 — базовые компоненты и мёртвый код
- Удалены `widgets/start_stop_mixin.py` (90 строк) и
  `widgets/filter_connector.py` (88 строк) вместе с их тестами (F-019, F-039).
- `Toolbar(id=None)` по умолчанию — дубль `#toolbar` на шести экранах
  исчез (F-006, F-018).
- `ContentPanel`, `Toolbar`, `ToolbarButton`, `StartStopWidget`,
  `ResizeHandle` зафиксированы как базовый набор (`COMPONENTS.md`).

### D2 — иерархия сообщений и reactive
- `ContentClipboardMixin` переведён с `@on` на соглашение об именах —
  в миксине `@on` не регистрируется вовсе (ADR-3, F-001).
- `AiModeSyncMixin` — единственное место подписки на `AiModeChanged`
  для трёх экранов (ADR-12, F-002).
- `ProxyDataTable` постит `ContextMenuRequest` / `CommentIconClicked`
  вместо `hasattr`-обхода предков (ADR-10, F-041).

### D3 — блокирующие вызовы → воркеры
- `AutoSaveMixin`: `_start_save_worker` + группа `SAVE_WORKER_GROUP`;
  отмена через `WorkerManager.cancel_group` — прежний `workers.cancel(name)`
  не существовал, `except Exception` это скрывал (ADR-11, F-045).
- Дубли `_do_auto_save` / `_cancel_save_workers` удалены из Intruder и Target.
- ~~Не тронуто: `asyncio.create_task` в `auto_scope.py` (F-014)~~ — закрыто
  2026-11-10: оба места переведены на `_spawn_tech_detect` / `run_worker`
  (F-048, ADR-14).

### D4 — мышь/клавиатура/resize
- `on_static_click` → `on_click` (F-043), `on_input_blur` →
  `on_input_blurred` (F-042), `DataTable.RowActivated` → `Click.chain == 2`
  (F-044).
- Адаптивность (`on_resize` → классы на корне, ADR-7, F-027) — **не сделана**:
  требует правки `.tcss` во всех 44 файлах и снапшотов.

### D5 — консолидация CSS
- F-008 закрыт 2026-11-10: 11 несовпадавших/мёртвых селекторов исправлены
  или удалены, `tools/check_tui_css.py` — блокирующий гейт CI и pre-commit
  (см. ниже). F-025 (CSS строкой в `.py`) и F-038 (дубли блоков) — не
  сделаны, но `IntruderFilterBar` уже переехал из inline `_INTRUDER_CSS` в
  `intruder_filter_bar.tcss`, а `filter_bar.tcss` (не загружался никем)
  удалён. Инвентарь: 44 `.tcss`, 0 hex-цветов, 0 `!important`, 2 файла не
  загружаются ни одним `.py`.

### D6 — pilot-тесты и снапшоты
- `tests/unit/tui/test_handler_name_dispatch.py`: AST-обход всех `on_*`
  в `pentool/tui`; имя обязано совпасть с реальным `Message.handler_name`.
  Тест падает на любом из восьми найденных дефектов.
- `tests/unit/tui/test_content_clipboard_mixin.py`: шесть тестов на эффект
  (замена выделения, вставка по курсору, дописывание в `RichLog`,
  пустой буфер → предупреждение).
- `TestComparerCopyPaste` переписан: подмена буфера и проверка `TextArea`
  вместо «клик не упал» (F-034).
- `TestCancelReachesWorkerManager` — на настоящем `WorkerManager`.
- Снапшоты: `pytest-textual-snapshot` объявлен, но не используется
  (F-032); 10 падений снапшотов предсуществующие (F-031).

### D7 — документация
- `SUMMARY.md`, `CONVENTIONS.md`, `COMPONENTS.md`, `pentool/tui/README.md`,
  обновлённый `wiki/tui.md`.

## 4. Самые значимые изменения

1. **`ContentClipboardMixin` на именованных хендлерах** — одна правка
   вернула копирование/вставку на шести экранах.
2. **`test_handler_name_dispatch.py`** — AST-гвард, который делает
   повторение этого класса ошибок невозможным.
3. **`AiModeSyncMixin`** — подписка и отписка в одном месте, вместо трёх
   разных реализаций с разной степенью поломки.
4. **`AutoSaveMixin._start_save_worker` + `cancel_group`** — отмена
   автосейва действительно доходит до воркера (тест на живом
   `WorkerManager`).
5. **`ProxyDataTable` постит сообщения** вместо `hasattr`-обхода предков —
   сообщение адресуется владельцу таблицы, а не «первому предку с таким
   методом».
6. **`services.tech_detector.fingerprint_from_html()`** — TUI перестал
   тянуть класс из `modules`.
7. **`Toolbar(id=None)`** — шесть экранов больше не делят один id.
8. **Переписанные тесты copy/paste** — проверяют буфер и `TextArea`,
   а не отсутствие исключения.
9. **Удалено 178 строк мёртвого кода** (`filter_connector`,
   `start_stop_mixin`) вместе с тестами к ним.
10. **`wiki/tui.md` + этот каталог** — инварианты Textual 8, на которых
    спотыкался код, теперь записаны рядом с кодом.

## 10. Чеклист «идеальный TUI»

Маркеры: ✅ — выполнено на этой ветке; ⬜ — не выполнено (с приоритетом).

**Диспетчеризация и сообщения**
- ✅ 1. Ни одного `on_*`-хендлера без реального `Message.handler_name` — проверяется AST-гвардом.
- ✅ 2. Ни одного `@on` внутри обычного миксина — проверяется тем же гвардом.
- ✅ 3. Виджет сообщает родителю сообщением, а не `hasattr`-обходом дерева (ADR-10).
- ✅ 4. Имена хендлеров выводятся из `__qualname__`, а не пишутся «на глаз».
- ⬜ 5. У каждого класса в `tui/messages.py` есть producer и handler в одном PR (ADR-2) — правило, не гейт.

**Жизненный цикл**
- ✅ 6. Каждая глобальная подписка снимается: `EventBus` — в `on_unmount`, `Config` — в `_on_exit_app` (ADR-12).
- ✅ 7. Отмена воркеров идёт через `cancel_group`/`cancel_node`, не по имени (ADR-11).
- ✅ 8. Нет `asyncio.create_task` вне `run_worker` — техдетект переведён на воркер группы `tech-detect` (F-048, ADR-14, 2026-11-10).
- ⬜ 9. Каждый долгоживущий воркер имеет `group=` (ADR-11, п.3) — группы есть у автосейва и техдетекта; остальные — долг.
- ⬜ 10. Таймеры, живущие дольше экрана, снимаются в `on_unmount` (F-013, P1).

**Слои и зависимости**
- ✅ 11. `tools/check_layers.py` — 0 нарушений, TUI не импортирует `modules`.
- ✅ 12. Composition root — только `PentoolApp` (ADR-1).
- ✅ 13. Сервисы внедряются через конструктор — `ProxyService` приходит в `ProxyScreen` из `compose`, присваивание приватного поля запрещено AST-тестом (F-012, 2026-11-11).
- ✅ 14. Один способ получить путь к БД — единственный `AppMixin._get_db_path`, локальные копии удалены (F-049, 2026-11-10).

**Компоненты**
- ✅ 15. Start/Pause/Resume/Stop — один виджет `StartStopWidget` (F-019).
- ✅ 16. Копирование/вставка содержимого — один миксин (F-017).
- ✅ 17. Тулбар без `id` по умолчанию (F-006, F-018).
- ✅ 18. Все диалоги наследуют `BaseDialog` — 12 мигрировано, включая PRO-шный `ChecksDialog`; Escape-привязки проверяются тестом (F-024, 2026-11-11).
- ✅ 19. Один циклер `OptionCycler` вместо двух (F-020, 2026-11-11).
- ✅ 20. Один фильтр-бар с конфигурацией вместо трёх копий: `HistoryFilterBar` + общий `.tcss`, `.replace`-генератор CSS удалён (F-021, 2026-11-11).
