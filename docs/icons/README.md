# Иконки канала и аккаунта

Готовый набор для Telegram-канала и GitHub-аккаунта. Сгенерировано
`tools/gen_social_icons.py` из официальных силуэтов [Simple Icons](https://simpleicons.org)
(лицензия CC0) — не перерисовка «на глаз».

## Что есть

Для каждого бренда — три стиля и два размера:

| Файл | Стиль | Куда подходит |
|---|---|---|
| `<brand>-brand.svg` / `-512.png` / `-128.png` | Фирменный цвет сервиса (Telegram `#29a1e2`, GitHub `#181717`), белый силуэт | аватар канала/аккаунта, кнопка-ссылка на сайте |
| `<brand>-pentool.svg` / `-512.png` / `-128.png` | Палитра проекта: тёмный диск `#0f1115`, акцентное кольцо и силуэт `#0178d4` | единый стиль с приложением и лендингом; аватар, если нужен «наш» вид |
| `<brand>-mono.svg` / `-512.png` / `-128.png` | Белый силуэт на прозрачном | вставка на любой фон: README, тёмные/светлые блоки, футер сайта |

`<brand>` — `telegram` или `github`.

Размеры: **512×512** (аватары Telegram/GitHub требуют ≥512), **128×128**
(фавиконки, кнопки в интерфейсе). SVG — вектор, масштабируется без потерь.

## Как перегенерировать

```bash
uv pip install cairosvg          # только для генерации, в зависимости проекта не входит
.venv/bin/python tools/gen_social_icons.py
```

Скрипт скачивает официальные SVG-силуэты (кеширует в `/tmp`), собирает три
стиля и растеризует PNG через cairosvg. Ничего не публикует и не трогает
остальные файлы.

## Ограничения

- Логотипы Telegram и GitHub — товарные знаки их владельцев; иконки уместны для
  ссылок на наш канал/аккаунт, но не как часть логотипа Pentool.
- В самом TUI иконки не используются: терминал не гарантирует отрисовку
  картинок, там остаются текстовые/глифовые обозначения.
