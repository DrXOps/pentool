## Баг

## Ограничения

- Исправить причину бага, не симптом.
- НЕ менять публичный API (сигнатуры методов).
- Изменять только файлы, непосредственно связанные с багом.
- Не рефакторить несвязанный код — только фикс.

## Что нужно сделать

1. Найти корневую причину (root cause).
2. Написать тест, который воспроизводит баг (тест должен УПАСТЬ до фикса).
3. Исправить баг.
4. Убедиться, что тест ПРОХОДИТ после фикса.
5. Убедиться, что существующие тесты не сломались: `pytest -x`
