# До релиза v0.6.0

Релиз — когда софт полностью рабочий: отдельного списка «после релиза» нет, есть порядок.
Блокеров нет (три закрыты, профилирование снято), ниже — что осталось по числам замеров.

Числа и разбор — [../audits/2026-11-26-tui-perf.md](../audits/2026-11-26-tui-perf.md).

## По порядку

| 7 | **Pending-строка в истории при `--smart`** | первый запрос виден только через ~1 с после старта | 0.5 дня |

## Как закрывать

1. **Resize**: не пересчитывать раскладку дважды за один переход; проверить `on_resize` на
   лишние `refresh(layout=True)` и на пересборку таблиц.
2. **Догрузка**: `add_rows`/`insert_rows` для старой страницы вместо `set_data` по всему кэшу;
   курсор и скролл должны оставаться на месте.
3. **Переключение**: уменьшать то, что рисуется — меньше виджетов на экране, ленивая отрисовка
   невидимых подвкладок, отказ от полного relayout при `show()`. Мерить тем же
   `tests/perf/tui_ui_scenarios.py`.
4. **Подвкладки**: перенос реестров вкладок Scanner/Repeater на `TabbedContentPanel`,
   затем Utils/Settings/Recon на `static_tabs`.
5. **Индикаторы**: события `ActivityChanged(module, active)` из прокси/скана/спайдера/MCP/AI,
   подписка индикатора, поллинг оставить редким fallback (5 с).
6. **Pending-строка**: вставить запись в историю при старте фетча и заменить реальной.
