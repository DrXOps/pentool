## Грабли этой сессии (чтобы не повторять)

- **`screen._X` у кооператоров** — источник двух крашей (`_TabId`). Кооператор получает явный
  контракт, а не приватный атрибут.
- **`TabbedContent.active` бросает `ValueError`**, а не только `NoMatches` — присваивать только
  через `TabbedContentPanel._set_active()`.
- **Строка с `border-bottom` требует `height: 2`** — иначе контент получает 0 строк и кнопки
  невидимы (так «пропали» инструменты Comparer).
- **Хранилище жило в экране**: без открытого Proxy-экрана трафик не писался в историю.
- **Моки в e2e подменяют `_load_entry_details`** — из-за этого шаг 6.4 (общий рендер панели
  деталей) дважды откатывался: полный прогон падал, поодиночке всё зелёное. Начинать с проверки
  этой гипотезы, а не с порядка `call_after_refresh`.
- **CI-флейки**: 4 случая гонок в пилот-тестах (Repeater/Intruder/Target). Правило: после
  `run_test()` ждать конкретного состояния (число виджетов, `active_tab_id`), а не «пары пульсов».
- **Публикация из WSL падает**, если в корне появился `subplans/` (артефакт старых скриптов);
  WSL-сеть иногда теряет DNS — тогда push делается из Windows с токеном из `~/.git-credentials`.
