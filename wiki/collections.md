# collections

**Универсальный движок фильтрации таблиц: предикаты, спецификации, трансляция в SQL.**

- **Связи:** [[tui]], [[storage]]
- **Код:** pentool/collections/
- **Источник:** pentool/collections/filter_predicate.py (docstring)
- **Обновлено:** 2026-11-05

## Назначение

Одна модель фильтрации для всех таблиц TUI. Позволяет описывать фильтр
декларативно и применять его либо в SQL (для больших таблиц), либо
in-memory (для уже загруженных данных).

## Публичный интерфейс

- `FilterOp` — enum операторов.
- `FilterPredicate` — один предикат: поле + оператор + значение.
- `FilterSpec` — набор предикатов с логикой AND/OR; умеет
  `to_sql() → (WHERE, params)`, `apply() → list[dict]`, `to_dict()/from_dict()`.
- `ColumnFilter` — описание UI-поля фильтрации.

## Инварианты и подводные камни

- `to_sql()` обязан параметризовать значения (никакой конкатенации) — иначе
  SQL-инъекция через поле фильтра.
- `apply()` и `to_sql()` должны давать эквивалентный результат на одних данных;
  расхождение — дефект.
- Сериализация `to_dict()/from_dict()` используется для сохранения фильтров.

## Связи

Используется [[tui]] (`FilterBar`, `filter_connector`) и [[storage]]
(SQL-адаптер).
